# 알려진 제한

[English](limitations.md) | **한국어** · [README로](../../README.ko.md)

- **xls는 읽기 전용**: 계산된 값만 읽습니다(xlrd가 수식 텍스트를 주지 않음). 저장하면 같은 이름의 `.xlsx`를 만들고 원본 `.xls`는 그대로 둡니다.
- 조건부 서식·스파크라인은 **표시하지 않지만 저장 시 보존**됩니다. 행을 삽입해도 이들의 범위는 이동하지 않습니다.
- 피벗 테이블: 보존·영역 표시·새로 고침·새로 만들기(표 형식, 열 필드 하나)를 지원합니다. 피벗 안의 편집과 피벗을 가로지르는 삽입·삭제·정렬은 거부됩니다. 원본의 새 항목 행은 Excel이 파일을 열 때 새로 고치면서 만듭니다.
- 파일의 피벗 차트는 보존·표시되고 제목·종류·서식을 바꿀 수 있습니다. 데이터는 피벗 테이블에서 오므로 데이터 범위, 행/열 전환, 분산형 변경은 할 수 없습니다(Excel과 같음). 새 피벗 차트는 행 필드가 하나인 피벗 테이블에서 만들 수 있습니다(삽입 → 피벗 차트).
- 동적 배열 수식은 결과를 분산(spill)하지 않고 왼쪽 위 값만 표시합니다.
- 이 앱이 계산할 수 없는 함수(LAMBDA, 추가 기능·VBA 함수 등)는 파일에 저장된 결과를 보여 주고, 저장할 때 수식을 그대로 둡니다.
- 차트 세부 서식(개별 색, 데이터 레이블, 보조 축)은 수정하면 기본 스타일로 다시 만들어집니다.
- 셀 단위 "셀 밀기" 삽입·삭제는 다른 수식의 참조를 조정하지 않습니다(행·열 전체 삽입·삭제는 조정).
- 인쇄는 Excel에서 하세요.
