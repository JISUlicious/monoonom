# 보안과 DRM

[English](security.md) | **한국어** · [README로](../../README.ko.md)

## 보안

- 서버는 `127.0.0.1`에만 바인딩하고 `Host` 헤더를 검사합니다(DNS 리바인딩 방지).
- 모든 API는 작업 폴더별 토큰이 필요합니다. 미리보기 주소의 `#t=…`(헤더로 보냄)로, 또는 토큰 없이 연 탭은 포트별 쿠키로 확인합니다. 변경 요청에는 사용자 지정 헤더도 필요해서, 다른 사이트의 요청은 CORS 사전 요청 없이 보낼 수 없습니다.
- 작업 폴더 밖의 파일은 열 수 없습니다(`--no-sandbox`로 해제).
- 서버 상태(`server.json`, 토큰, 로그, 백업)는 `<작업 폴더>/.monoonom/`에 있습니다. 버전 관리에 넣지 마세요.
- 토큰이 붙은 미리보기 주소가 유출되었다면 `xl.py stop` 뒤 `xl.py serve --new-token`을 실행하고 새 주소로 다시 여세요.

## 네트워크: 무엇이 컴퓨터 밖으로 나가는가

MoNooNoM 자체는 인터넷으로 아무것도 보내지 않습니다. 사용 통계, 업데이트 확인, 웹 폰트·CDN이 없습니다.

- **서버와 CLI**: 서버는 `127.0.0.1`에서만 받고, `xl.py`는 그 서버하고만 통신합니다. 수식 엔진에 웹에서 가져오는
  함수(`WEBSERVICE` 등)가 없습니다.
- **미리보기 화면**: Content-Security-Policy(`default-src 'self'; connect-src 'self'; form-action 'none'; …`)와 함께
  보내므로, 화면에서 다른 호스트로 가는 요청은 브라우저가 막습니다. 끼워 넣은 스크립트가 있더라도 화면을 통해
  통합 문서 데이터가 나갈 수 없습니다. 차트(Chart.js)를 비롯한 모든 스크립트는 패키지에 들어 있습니다.
- **셀의 링크**: Ctrl+클릭은 `http`, `https`, `mailto` 링크만 새 탭에서 `Referer` 없이(`noreferrer`) 엽니다. 통합 문서
  안의 위치(`#시트!A1`)는 그 자리에서 보여 주고, 그 밖의 종류(파일 경로, `javascript:`)는 열지 않습니다. 웹 링크를
  여는 것은 Excel과 마찬가지로 그 사이트를 방문하는 것입니다.
- **에이전트의 모델**: 에이전트가 `xl.py read`·`describe`로 읽은 내용은 대화의 일부가 되어 에이전트의 모델 제공자에게
  갑니다(에이전트가 읽는 다른 모든 것과 같음). 중요하면 에이전트가 읽는 범위를 좁히세요(시트 전체가 아니라 범위).
- **설치할 때만**: `pip install`(PyPI), `npx skills add`(npm, GitHub), Claude Code 플러그인 마켓플레이스(GitHub)가
  패키지를 내려받습니다. 실행 중에는 아무것도 내려받지 않습니다.
- **DRM 훅**(아래): 직접 설정한 코드를 실행합니다. 그 코드가 무엇을 보내는지는 그 코드에 달려 있습니다.

## DRM 환경

브라우저는 파일 내용을 읽지 않고 경로만 보냅니다. 모든 읽기·쓰기가 `scripts/server/fileio.py`를 지나므로, 허가된
프로세스(Python)에 투명 복호화를 해 주는 DRM이면 그대로 동작합니다. DRM SDK를 호출해야 하면 함수를 끼웁니다:

```bash
MONOONOM_READ_HOOK=mypkg.drm:read_file     # (path) -> bytes
MONOONOM_WRITE_HOOK=mypkg.drm:write_file   # (path, data: bytes) -> None
```

파일 식별자를 추적하는 DRM을 위해 임시 파일+이름 바꾸기 없이 같은 경로에 직접 씁니다. 읽은 파일이 zip(xlsx)이 아니면
읽기 훅을 지정하라는 안내와 함께 오류를 냅니다. 페이지에 파일을 끌어 놓는 것은 일부러 막았습니다(파일은 서버를 통해 엽니다).
